# After-Effects-Expression-Library
Made for non-coders that edit on Adobe After Effects (no tutorials on how to implement/made for more advanced AE users).  
A collection of useful After Effects expressions, curated from existing libraries and organized for motion designers without a coding background. 

Expressions sourced from the following: 
https://www.plainlyvideos.com/after-effects-expressions-library 
https://aereference.com/resources
